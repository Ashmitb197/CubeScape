# 🧩 Cubescape – 3D Puzzle Adventure (Unity)

**Cubescape** is a 3D puzzle-platformer built in **Unity**, designed around cooperative local multiplayer. One player uses a **controller**, the other uses **keyboard & mouse**. Together, they must navigate cleverly designed levels using **pressure plates**, **switches**, **gates**, and environmental logic systems.

---

## 🎮 Features

- 🧠 **Puzzle Mechanics**: Engage with pressure plates, toggle switches, timed gates, and more to solve puzzles and unlock paths.
- 🧑‍🤝‍🧑 **Local Co-op Multiplayer**: Two players control different characters with different input schemes — perfect for couch play.
  - Player 1: **Keyboard + Mouse**
  - Player 2: **Controller (Xbox / PS4 / Generic)**
- 🌌 **3D Minimalist World**: Stylized visual design with clear geometry and smooth transitions.
- 🔁 **Replayable Level Design**: Levels are built to encourage experimentation and teamwork.
- 🧩 **Integrated Logic System**: Switch-based environment triggers with real-time feedback.

---

## 🛠️ Built With

- [Unity](https://unity.com/)
- C# scripting
- Unity Classic Input System (for dual input handling)
